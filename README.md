# Embedded Linux Learning

嵌入式 Linux 学习仓库，用于整理 C++、Linux 系统编程、网络编程和 ARM Linux 的笔记、练习及项目。

## 目录

| 目录 | 内容 |
| --- | --- |
| `01_cpp_basic/` | C++ 基础 |
| `02_modern_cpp/` | 现代 C++ |
| `03_linux_system/` | Linux 系统编程 |
| `04_network/` | 网络编程 |
| `05_arm_linux/` | ARM Linux |
| `projects/` | 综合实践项目 |

## 在 VS Code 中同步

1. 编辑并保存笔记或代码。
2. 按 `Ctrl+Shift+G` 打开源代码管理，暂存需要提交的文件。
3. 填写提交说明并提交。
4. 点击“同步更改”将提交上传到 GitHub。

也可以在项目终端中使用：

```sh
git status
git add <文件路径>
git commit -m "添加学习笔记"
git push
```

Linux 和 ARM 相关示例在对应的 Linux 环境中编译、运行。
